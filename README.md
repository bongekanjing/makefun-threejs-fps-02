VESPER YARD is a round-based tactical first-person shooter in the Counter-Strike style — your own map, art, sounds and names, never a copy. Five against five on a night container yard on the harbour quay: plant the spike at site A (Crane) or site B (Dock), or wipe the other crew. Money between rounds buys rifles, SMGs, a sniper, a shotgun, Kevlar and grenades; gunfire rewards accuracy over speed. Single-player against nine bots, running in a desktop browser on three.js, from static files with no build step and no network request.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
